## 4. The Dark Horse Tavern: presses (DO 2)

Counted on the player's path, a press being a link or a button. `k` is the number of rolls passed in a game of dice
(at most 2), `d` the number of pairs drawn in a game of stones.

| | 1.1.2 | `c45337e` | Now |
|---|---|---|---|
| Dice, one game | Bet (the first roll), `k` Pass, Keep (the result): `k + 2`; then Play again before the next Bet | `k + 2`; the Keep's page shows the result and the next game's Bet | Unchanged |
| Stones, one game | Like Pair or Unlike Pair, Bet (draws the first pair), a Continue for each further pair, a Continue that settles: `d + 2`; then Play again before the next choice | The choice, the Bet (drew nothing), a Draw for every pair, the Settle: `d + 3`; the settle page shows the next game's choice | `d + 2`: the Bet draws the first pair, as 1.1.2's did; the rest as before |
| Five-six, one roll | Roll the Dice (the result); then Play again and Roll for the next: two a roll after the first | One Roll a roll; its page shows the result and the next Roll | Unchanged |
| Into the tavern from the forest's event | One link | One | Unchanged |
| Riding in on a mount; leaving the tavern | One link each | A link, then a page with one button to confirm: two each | Unchanged, recorded |

So no game takes more presses a round than 1.1.2's, and each takes one fewer between games (no Play again). The fix
is in `modules/game_stones.php`: inside the same player mutation as the bet, `StonesGame::act()` draws the first pair,
so the bet and its first pair are one stored change; the per-action token, CSRF, the escrowed bet and the server's
draws (`e_rand`) are as before. The first pair cannot end a game (16 stones; a game ends past 8 in a pile).

The one difference left is the tavern's door: riding in on a mount and leaving each change the player (the forest's
event state, the wager), and Resurrection changes state only by a POST with CSRF and an action token, never by a link;
the navigation panel holds only links, so each is a link to a page with one button. Recorded for Jim (release notes,
known issues; `docs/CHANGES-FROM-1.1.2.md`).
