### The links

`resurrection_icon_links()` (`lib/output.php`) returns the three relative links:

```html
<link rel="icon" href="favicon.ico" sizes="any"><link rel="icon" href="favicon.svg" type="image/svg+xml"><link rel="apple-touch-icon" href="apple-touch-icon.png">
```

They go into `{headscript}`, which `lib/pageparts.php` fills in exactly two places: `page_footer()` (every page, the
safe frame, the operator frame and `setup.php`'s frame) and `popup_header()` (every popup). It replaces 1.1.2's
`<LINK REL="shortcut icon" HREF="favicon.ico" TYPE="image/x-icon"/>`. The links load same-origin images, which the
enforced CSP's `img-src 'self'` allows; the template checks are untouched (no required tag, credit or link changes).
