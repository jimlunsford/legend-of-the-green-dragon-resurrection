### Cause

The test needed a tool CI does not have, Chromium through Playwright for Node. Here Playwright is installed, so the test
ran and passed in every local shard, and the skip showed only in CI.

### The change

1. The redraw left the test suite. It is now the local check `python3 scripts/art/build_favicon.py --check`: it draws
   the source again with the recorded rasterizer into a temporary folder, writes nothing in the tree, and compares each
   of the four icon files and the manifest with the committed ones byte for byte. It prints one line per file and exits
   0 when all match, 1 on any difference, and 2 when it cannot draw (no Node, Playwright or Chromium, or another
   version). `--check` takes no other option.
2. The build now writes a manifest, `scripts/art/favicon-manifest.json`: the source's name and SHA-256, the rasterizer's
   versions, and each icon file's name, size in bytes, pixel dimensions and SHA-256. The same files always give the same
   text, and `--check` compares it too. It sits in `scripts/art/`, which the package leaves out (the host guide's "Do
   not upload" list). Rebuilding wrote the four icon files unchanged; only the manifest is new.
3. `tests/tooling/test_favicon.py` checks what CI can prove without a browser. The rebuild test is gone; five tests
   replace it, and the five kept tests are unchanged:
   - `test_the_committed_files_match_the_manifest`: each file's size, SHA-256 and pixel dimensions (read by the script
     and, for the PNGs and the ICO, by the test's own readers) equal the manifest's, which names the four files in
     order, the pinned source SHA-256 and the script's recorded Chromium and Playwright.
   - `test_the_manifest_is_the_scripts_own_record_of_the_committed_files`: the script, given the committed files,
     writes the committed manifest byte for byte.
   - `test_the_svg_check_finds_a_script_and_an_external_reference`: the source has neither, and the plain-drawing check
     catches a planted `<script>`, an external `<image href>` and an external `url()`.
   - `test_the_redraw_check_compares_every_byte`: `--check`'s comparison reports one flipped byte in each of the five
     files, at the right offset, and a missing file.
   - `test_the_redraw_check_never_passes_without_the_rasterizer`: with Playwright's browsers hidden, `--check` exits 2
     and says it cannot redraw, and the tree is untouched.
   Kept: the four files exist with their sizes; the ICO holds 16, 32 and 48 and `favicon.png` is its 32 px image;
   `favicon.svg` equals the source and is a plain drawing; the encoder gives the committed bytes again; every frame's
