# Resurrection versioning

Historical source identity is Legend of the Green Dragon 1.1.2 Dragonprime Edition. Resurrection owns a separate version line: **0.x** during development, with **1.0.0** reserved for an actual future stable Resurrection release.

Use `MAJOR.MINOR.PATCH` style. Before 1.0, the modern product contract is still being established. Patch releases cover focused corrections or small contained work; minor releases cover larger development milestones. Document breaking changes even during 0.x.

Repository creation is not a version milestone. Foundation has no assigned application version. Do not label the first Resurrection work 1.1.3, create v1.1.2 as if it were an upstream release, or create v0.1.0 merely to finish setup.

`historical-source-1.1.2` is an annotated preservation marker targeting the exact imported source. It is not a release, must not move, and must not receive a GitHub Release. Future release tags will identify reviewed Resurrection milestones, with test/security/provenance evidence and an explicit release decision.
